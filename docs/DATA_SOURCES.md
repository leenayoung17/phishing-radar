# 데이터 출처와 사용 조건

피싱 탐지 레이더의 통계 모델(`src/lib/analysis/model/model.json`)은 아래 두 데이터로 학습했습니다.
원본 데이터 파일은 저장소에 올리지 않습니다(`important/` 폴더는 Git 제외).

이 서비스는 **비영리 목적**으로만 운영합니다. 상업적으로 이용하려면 아래 조건을 다시 확인하고,
조건이 맞지 않는 데이터를 빼고 모델을 다시 학습해야 합니다.

## 1. 한국어 스미싱 메시지 데이터 (`smishing.csv`)
- 출처: Hugging Face `jmjmjm3/kor-smishing-message`
- 라이선스: CC BY-NC-SA 4.0 (저작자 표시, 비영리, 동일조건 변경 허락)
- 참고: 원본의 수집 방식·출처는 명시되어 있지 않습니다.

## 2. 한국어 메시지 데이터 (`lgaidataset.csv`)
- 출처: Hugging Face `meal-bbang/Korean_message`
- 라이선스: 명시되어 있지 않음
- 데이터 제공자 답변(2026-11-06 확인, 요약):
  - 생성형 AI로 만든 택배·스팸·일상 문자에, 여러 출처의 문자를 더해 만들었다.
  - 일부 출처는 사이트가 없어졌거나 라이선스가 명시되어 있지 않다
    (참고 출처: GitHub `Ez-Sy01/KOR_phishing_Detect-Dataset`).
  - 상업적 이용이라면 사용하지 않는 것이 좋고, 그렇지 않다면 사용해도 된다는 의견.
- 라벨 처리: 클래스 2 = 스미싱, 클래스 1·3 = 정상 (서비스 운영자 지정)
- 주의: 일부가 AI로 생성된 문자이므로, 이 데이터로 잰 성능은 실제 문자보다 높게 나올 수 있습니다.

## 3. 검증용 문장
- `src/lib/analysis/cases.ts`, `validation-sets.ts` 의 문장은 직접 작성한 가상의 문장입니다.
- 규칙을 만든 사람이 쓴 문장이라 실제 성능보다 좋게 나올 수 있어, 동작 확인용으로만 씁니다.
